二、软件概述

2.1 产品定位

中数云科智行流是一款面向全行业的通用型 SaaS 智能客户关系管理平台。系统以「可配置性」为核心竞争力，支持企业根据自身行业特点自定义客户字段、销售管道、仪表盘等核心业务模块，实现从营销获客、销售转化到客户服务、数据分析的全链路数字化管理。

2.2 目标用户

  • 中小型企业：需要轻量级、快速上线的CRM系统
  • 销售团队：需要客户跟进、销售管道、成交管理工具
  • 营销部门：需要广告投放追踪、落地页获客、活动裂变能力
  • 客服部门：需要企业微信集成、收件箱统一接待、工单管理
  • 管理层：需要数据分析仪表盘、团队业绩报表、运营洞察

2.3 核心价值

  • 全行业通用：通过自定义字段、可配置管道、可配置仪表盘三大能力，支撑教培、医美、B2B、房产、助贷等不同行业的业务需求
  • AI 赋能：集成大语言模型（DeepSeek / 通义千问），提供AI跟进话术生成、客户画像摘要、智能跟进提醒等智能化能力
  • 企业微信深度集成：对接企业微信客户联系、消息推送、渠道活码、回调处理等完整能力
  • 全链路闭环：从广告投放追踪 → 落地页留资 → 客户管理 → 销售跟进 → 成交订单 → 服务工单，形成完整业务闭环

四、核心功能模块

4.1 客户管理模块（核心模块）

提供客户全生命周期管理，包括客户信息的增删改查、批量导入导出、标签分类、客户分群、跟进记录、转移分配等。主要功能包括：客户列表（搜索、筛选、排序、分页）；客户详情（基本信息、跟进历史、订单记录、附件管理）；批量操作（多选批量标签、批量转移、批量变阶段、批量删除）；批量导入导出（CSV/Excel，自动映射自定义字段）；自定义字段系统（EAV模型，租户级字段定义）；行业模板（教培/医美/B2B/助贷等预置模板）。

4.2 销售管道模块

可配置的销售阶段管理，支持看板视图展示客户在销售管道中的推进状态。包括：可配置销售管道（租户级JSON定义）；5个行业管道模板（房产/教培/医美/B2B/助贷）；销售看板（动态加载阶段，拖拽移动客户）；目标分配与进展追踪；阶段停留时间监控。

4.3 企业微信集成模块

深度对接企业微信开放平台，实现客户联系、消息管理、渠道分析等能力。包括：企业微信客户同步（自动同步外部联系人）；客户消息收发（文本/多媒体）；渠道活码（分组与员工活码）；客户添加回调（自动入库触发流程）；群发任务；消息加密解密（AES-256-CBC）。

4.4 AI 智能能力模块

集成大语言模型，为销售和服务人员提供智能化辅助。包括：AI跟进话术生成（三种风格）；AI客户画像摘要（基于历史数据）；AI智能跟进提醒（三类告警）；AI文案生成；AI员工自动回复；AI客服；AI教练建议。

4.5 营销获客模块

覆盖从广告投放到客户转化的完整营销链路。包括：落地页构建器；落地页留资自动入库；广告追踪与归因；广告消耗同步（腾讯广告Marketing API）；广告ROI分析；裂变活动；群发任务。

4.6 流程自动化引擎

可视化配置业务流程，实现营销、销售、服务的自动化流转。包括：可视化流程构建器（拖拽节点、连线、条件分支）；多种触发器（新客户进入、阶段变更、跟进到期、订单成交等）；多种动作（发消息、分配任务、打标签、发通知等）；流程执行日志与监控。

4.7 数据分析模块

多维度数据分析和可视化报表。包括：可配置仪表盘（19个Widget + 5个行业模板）；漏斗分析；团队业绩；客户分析；排行榜；时间筛选与同比对比；图表可视化（折线图、柱状图、饼图、漏斗图）。

4.8 计费与订阅模块

完整的SaaS计费体系。包括：多套餐体系；余额充值（微信支付、支付宝、线下转账）；自动续费；用量加购包；在线发票；优惠码系统；付款墙方案。

五、软件特色与创新点

5.1 全行业可配置性（核心竞争力）

本系统区别于传统垂直行业CRM，通过三大可配置能力实现「所有行业都能用」：(1) 自定义字段系统——基于EAV模型，租户可自行定义客户字段；(2) 可配置销售管道——租户可自定义销售阶段；(3) 可配置仪表盘——19个可拖拽Widget，预置5个行业模板。

5.2 AI 深度集成

国产大模型集成（DeepSeek / 通义千问），合规可控；AI能力覆盖销售话术、客户画像、智能提醒、自动回复等多个场景。

5.3 企业微信生态深度融合

完整对接企微客户联系、消息推送、渠道活码、回调事件等能力，支持企微客户自动同步、消息自动入库。

5.4 SaaS 全链路闭环

从广告投放追踪 → 落地页获客 → 客户管理 → 销售跟进 → 成交订单 → 服务工单 → 数据分析，形成完整的业务数据闭环。

5.5 完善的商业化能力

多套餐多通道支付体系，余额/续费/加购/发票完整闭环，平台运营后台与支付对账。

七、系统安全设计

  • 认证与鉴权：JWT无状态认证，bcrypt密码哈希，RBAC角色权限控制，数据级权限隔离
  • 数据安全：多租户数据隔离，SQL注入防护（Sequelize ORM参数化查询），XSS防护，CORS白名单，速率限制，支付回调签名验证
  • 传输安全：全站HTTPS，API请求JWT Token鉴权，敏感配置通过环境变量注入
