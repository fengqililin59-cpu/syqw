## 二、软件概述

### 2.1 产品定位

中数云科智行流是一款**面向全行业的通用型 SaaS 智能客户关系管理平台**。系统以「可配置性」为核心竞争力，支持企业根据自身行业特点自定义客户字段、销售管道、仪表盘等核心业务模块，实现从营销获客、销售转化到客户服务、数据分析的全链路数字化管理。

### 2.2 目标用户

- **中小型企业**：需要轻量级、快速上线的CRM系统
- **销售团队**：需要客户跟进、销售管道、成交管理工具
- **营销部门**：需要广告投放追踪、落地页获客、活动裂变能力
- **客服部门**：需要企业微信集成、收件箱统一接待、工单管理
- **管理层**：需要数据分析仪表盘、团队业绩报表、运营洞察

### 2.3 核心价值

- **全行业通用**：通过自定义字段、可配置管道、可配置仪表盘三大能力，支撑教培、医美、B2B、房产、助贷等不同行业的业务需求
- **AI 赋能**：集成大语言模型（DeepSeek / 通义千问），提供AI跟进话术生成、客户画像摘要、智能跟进提醒等智能化能力
- **企业微信深度集成**：对接企业微信客户联系、消息推送、渠道活码、回调处理等完整能力
- **全链路闭环**：从广告投放追踪 → 落地页留资 → 客户管理 → 销售跟进 → 成交订单 → 服务工单，形成完整业务闭环

## 三、技术架构

### 3.1 整体架构

系统采用 **B/S 前后端分离架构**，分为三大层：

```

│                    前端展示层                         │
│  React 19 + TypeScript + Vite + Tailwind CSS        │
│  ┌──────────┬──────────┬──────────┬──────────┐     │
│  │ 仪表盘    │ 客户管理  │ 销售管道  │ 数据分析  │     │
│  │ AI工作台  │ 营销活动  │ 收件箱    │ 系统设置  │     │
│  └──────────┴──────────┴──────────┴──────────┘     │
├─────────────────────────────────────────────────────┤
│                    业务服务层                         │
│  Node.js + Express + Sequelize ORM                  │
│  ┌──────────┬──────────┬──────────┬──────────┐     │
│  │61个控制器 │147个服务 │106个模型 │58个路由  │     │
│  │认证鉴权    │客户管理  │营销引擎  │AI服务    │     │
│  │流程引擎    │计费系统  │企微集成  │工单服务  │     │
│  └──────────┴──────────┴──────────┴──────────┘     │
├─────────────────────────────────────────────────────┤
│                    数据持久层                         │
│  MySQL 8.0 + 100+ 数据库迁移脚本                     │
│  ┌──────────┬──────────┬──────────┬──────────┐     │
│  │ 客户数据  │ 业务数据  │ 营销数据  │ 分析数据  │     │
│  │ 租户隔离  │ RBAC权限  │ 审计日志  │ 聚合表    │     │
│  └──────────┴──────────┴──────────┴──────────┘     │
├─────────────────────────────────────────────────────┤
│                    外部集成层                         │
│  企业微信API │ 微信支付API │ 支付宝API │ 腾讯云TCCC │
│  腾讯广告API │ AI大模型API │ SMTP邮件   │ 短信网关   │
```

## 四、核心功能模块

### 4.1 客户管理模块（核心模块）

**功能描述**：提供客户全生命周期管理，包括客户信息的增删改查、批量导入导出、标签分类、客户分群、跟进记录、转移分配等。

**主要功能点**：
- 客户列表（搜索、筛选、排序、分页）
- 客户详情（基本信息、跟进历史、订单记录、附件管理）
- 批量操作（多选批量标签、批量转移、批量变阶段、批量删除）
- 批量导入（CSV/Excel，自动映射自定义字段）
- 批量导出（字段选择对话框，CSV/Excel双格式）
- **自定义字段系统**（EAV模型，租户级字段定义）
- **行业模板**（教培/医美/B2B/助贷 4个预置模板）
- 客户标签管理与分类
- 客户分群（静态/动态规则）
- 客户转移与回收

### 4.2 销售管道模块

**功能描述**：可配置的销售阶段管理，支持看板视图展示客户在销售管道中的推进状态。

**主要功能点**：
- **可配置销售管道**（租户级配置，JSON stages定义）
- **5个行业管道模板**（房产/教培/医美/B2B/助贷）
- 销售看板（动态加载管道阶段，拖拽移动客户）
- 目标分配与进展追踪
- 阶段停留时间监控

### 4.3 企业微信集成模块

**功能描述**：深度对接企业微信开放平台，实现客户联系、消息管理、渠道分析等能力。

**主要功能点**：
- 企业微信客户同步（自动同步外部联系人）
- 客户消息收发（文本消息、多媒体文件）
- 渠道活码（分组与员工活码，可动态更换成员）
- 客户添加回调（自动入库并触发新客户流程）
- 群发任务（企业群发、客户群发）
- 消息加密解密（WXBizMsgCrypt，AES-256-CBC）
- Access Token 自动缓存与管理
- 企微客户消息记录存储与查询

### 4.4 AI 智能能力模块

**功能描述**：集成大语言模型，为销售和服务人员提供智能化辅助。

**主要功能点**：
- **AI跟进话术生成**（三种风格：关怀型/价值型/促成型）
- **AI客户画像摘要**（基于客户画像+跟进历史生成摘要）
- **AI智能跟进提醒**（高意向沉默/管道滞留/紧急待跟三类告警）
- AI文案生成（营销文案、朋友圈文案）
- AI员工（自动草稿回复、审核、运营统计）
- AI客服（自动回复、人工接管、服务统计）
- AI教练建议（基于销售数据生成辅导建议）

### 4.5 营销获客模块

**功能描述**：覆盖从广告投放到客户转化的完整营销链路。

**主要功能点**：
- **落地页构建器**（拖拽式组件搭建，无需编码）
- **落地页留资自动入库**（表单提交→自动创建客户→触发流程引擎）
- **广告追踪**（点击跳转追踪、多平台归因）
- **广告消耗同步**（腾讯广告Marketing API，日报消耗自动同步）
- **广告ROI分析**（按渠道、按活动的投入产出比分析）
- **裂变活动**（邀请奖励、进度追踪、排行榜）
- **群发任务**（批量消息发送、定时调度）
- 营销事件追踪与归因

### 4.6 流程自动化引擎

**功能描述**：可视化配置业务流程，实现营销、销售、服务的自动化流转。

**主要功能点**：
- **可视化流程构建器**（拖拽节点、连线、条件分支）
- **触发器类型**：新客户进入、阶段变更、标签变更、跟进到期、订单成交等
- **动作类型**：发送消息、分配任务、变更标签、发送通知等
- 流程执行日志与监控
- 自动跟进规则（基于规则的自动化触达）

### 4.7 数据分析模块

**功能描述**：多维度数据分析和可视化报表，辅助经营决策。

**主要功能点**：
- **可配置仪表盘**（19个可配置Widget + 5个行业模板）
- **漏斗分析**（各阶段转化率、流失分析）
- **团队业绩**（按人/按时间/按渠道的业绩统计）
- **客户分析**（来源分析、活跃度分析、价值分层）
- **排行榜**（销售排行榜、跟进排行榜）
- 时间筛选、同比环比对比
- 图表可视化（折线图、柱状图、饼图、漏斗图）

### 4.8 计费与订阅模块

**功能描述**：完整的SaaS计费体系，支持多套餐、余额充值、自动续费等。

**主要功能点**：
- **多套餐体系**（免费版/专业版/企业版）
- **余额充值**（微信支付、支付宝、线下转账三通道）
- **自动续费**（余额自动扣款、续费提醒）
- **用量加购包**（AI配额、短信配额、存储空间）
- 在线发票（电子发票申请与管理）
- **优惠码系统**（兑换码、折扣码）
- **付款墙方案**（Feature Flag 控制付费功能门禁）

## 五、软件特色与创新点

### 5.1 全行业可配置性（核心竞争力）

本系统区别于传统垂直行业CRM，通过**三大可配置能力**实现「所有行业都能用」：
1. **自定义字段系统**：基于EAV（实体-属性-值）模型，租户可自行定义客户字段（文本/数字/下拉/日期等），并预置4个行业模板
2. **可配置销售管道**：租户可自定义销售阶段（JSON定义），预置5个行业管道模板
3. **可配置仪表盘**：19个可拖拽Widget，支持指标自定义，预置5个行业仪表盘模板

### 5.2 AI 深度集成

- 国产大模型集成（DeepSeek / 通义千问），合规可控
- AI能力覆盖销售话术、客户画像、智能提醒、自动回复等多个场景
- AI辅助销售决策，而非替代人工判断

### 5.3 企业微信生态深度融合

- 完整对接企微客户联系、消息推送、渠道活码、回调事件等能力
- 支持企微客户自动同步、消息自动入库
- 企微渠道获客→CRM管理的无缝衔接

### 5.4 SaaS全链路闭环

从广告投放追踪 → 落地页获客 → 客户管理 → 销售跟进 → 成交订单 → 服务工单 → 数据分析，形成完整的业务数据闭环。

### 5.5 完善的商业化能力

- 多套餐多通道支付体系
- 余额/续费/加购/发票完整闭环
- 平台运营后台与支付对账

## 七、系统安全设计

### 7.1 认证与鉴权

- JWT（JSON Web Token）无状态认证
- 密码采用 bcrypt 哈希加密存储
- 支持角色级权限控制（RBAC）
- 数据级权限隔离（销售仅看自己负责的客户）

### 7.2 数据安全

- 多租户数据隔离（tenant_id 级别）
- SQL注入防护（Sequelize ORM 参数化查询）
- XSS攻击防护
- CORS 跨域白名单控制
- 速率限制（express-rate-limit）
- 支付回调签名验证（微信支付API v3 / 支付宝RSA2）

### 7.3 传输安全

- 全站 HTTPS（Let's Encrypt / 商业SSL证书）
- API 请求均需携带 JWT Token
- 敏感配置通过环境变量注入，不写入代码
