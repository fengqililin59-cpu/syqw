中数云科 · 演示口播稿（飞书/打印版）
================================

入口：https://wework.syzs.top/login → 点「免费体验演示系统」
时长：5～8 分钟｜最短 3 分钟只念「最短版」
铁律：AI 写草稿，销售点确认才发（不承诺自动乱回）

--------------------------------
一、通用开场（30 秒，所有行业先念）
--------------------------------

您好，我是中数云科。很多团队客户都在企微里，但不知道今天该先跟谁、话术谁写、销售一走客户就丢。

我们做的是：企微里的销售副驾驶——谁该跟、怎么说、您来发。
我用几分钟带您点一遍，不讲功能表。

【停一下，问对方】
您这边现在客户主要怎么管？表格、微信备注，还是已经有 SCRM？

（等对方答完，再进对应行业章节）


--------------------------------
二、教培招生
--------------------------------

【开场 20 秒】
教培最痛的是：留资很多，顾问跟不完；体验课约了又鸽子；试听后没人盯成交。
中数云科帮您把线索进企微、标出高意向家长、AI 帮写邀约话术，顾问确认后再发。

【点屏 + 口播】
1）仪表盘 / 待跟进
「顾问每天先打开这里：今天该回访哪几位家长，不用在微信里翻几百个好友。」

2）客户列表 → 筛高意向
「系统按互动打分。这几位是最近意向升高的，优先约体验课。」

3）点进一位家长 → AI 话术
「比如体验课邀约，AI 已按教培场景写好草稿。顾问看一眼，合适就复制发出——不会自动替您发。」

4）跟进记录 / 阶段
「试听前、试听后、报价、成交，阶段都在这里。换顾问交接也不用问‘这家长聊到哪了’。」

5）（可选）销售看板
「校长看这一眼：卡在邀约的多，还是卡在成交的多，好派资源。」

【收尾】
方便先开 14 天试用吗？我们帮您把本周一条招生渠道的线索跟到体验课约课，下周一起看转化。

【最短 3 分钟】
留资多跟不完 → 待跟进 → 高意向家长 → AI 体验课话术（人审）→ 邀试用。


--------------------------------
三、美业 / 医美门店
--------------------------------

【开场 20 秒】
美业最痛的是：到店咨询加了微，顾问一忙就漏回访；老客复购靠感觉；员工一走把微信客户带走。
中数云科把客户留在门店体系里，告诉顾问今天该回访谁、话术怎么开口，人确认再发。

【点屏 + 口播】
1）仪表盘 / 待跟进
「前台、顾问早班先看：昨天咨询未到店的、该做回访的，一目了然。」

2）客户列表 → 高意向 / 即将流失
「咨询过项目、聊过价格但没定的，系统会标出来，避免沉在聊天记录里。」

3）客户详情 → AI 话术
「比如预约到店、术后回访，AI 出草稿，顾问改一两个字再发。发送权在门店，不在机器人。」

4）跟进时间线
「咨询、到店、成交、复购提醒都在一条时间线上，换顾问也能接着聊。」

5）（可选）本周战果
「店长看本周跟了多少、约到店多少，比只看收银报表更早发现问题。」

【收尾】
方便先用演示账号感受一周，或开 14 天试用，把本店咨询未成交名单导进来跑一轮回访吗？

【最短 3 分钟】
漏回访 → 待跟进 → 高意向客户 → AI 预约话术（人审）→ 邀试用。


--------------------------------
四、B2B / 企服销售
--------------------------------

【开场 20 秒】
B2B 最痛的是：线索进了企微，跟进周期长；多轮沟通没人记；老板不知道卡在方案还是报价。
中数云科把线索阶段管起来，意向升高就预警，AI 帮写邀约演示话术，销售确认再发。

【点屏 + 口播】
1）仪表盘 / 高意向预警
「决策信号一出现——反复问价格、要方案——系统会提醒销售先跟这位。」

2）客户列表 → 阶段筛选
「从线索、接触、方案、谈判到成交，每一步看得见，不是只靠销售口头汇报。」

3）客户详情 → AI 话术
「例如演示邀约、方案跟进，AI 出草稿；对外发送必须销售点确认。」

4）销售看板
「您看卡在‘方案’这一列的数量——资源该补售前，还是补报价，老板一眼能定。」

5）（可选，对方在投流时）广告 ROI
「如果您也在投流获客，这里能把投入、线索、跟进串起来算获客成本，不只看广告后台点击。」

【收尾】
方便先开 14 天专业版试用？我们帮您把一条主线索池跑通：进库 → 阶段 → 本周战果，下周一起复盘。

【最短 3 分钟】
漏跟/周期长 → 意向预警 → 看板阶段 → AI 演示邀约（人审）→ 邀试用。


--------------------------------
五、对方打断时怎么答（背下来）
--------------------------------

问：和微伴/尘峰比呢？
答：他们功能面很全。我们强在每天谁先跟、AI 草稿人审、投流能不能算清账。可以只当补充，不必推倒重来。

问：和扣子/机器人比呢？
答：扣子擅长造对话 Agent；我们管企微客户资产和销售跟进闭环。复杂闲聊可用扣子，成交跟进放我们这儿。

问：会不会 AI 乱回客户？
答：默认只写草稿，销售确认才发。老板可以关自动发送，先用人审模式跑。

问：多少钱？
答：先 14 天试用验证。专业版大约每月三百多起，按团队规模升级。满意再谈年框。

问：我们先看看资料。
答：好的。我把演示链接发您：登录页点免费体验。您方便的话本周定 15 分钟，我陪您过一遍自己的场景。


--------------------------------

--------------------------------

1. 发链接：https://wework.syzs.top/login（提醒点「免费体验」）
2. 问定下一步：试用开通 / 下周复盘 / 加企微
3. 当场记下：行业、团队人数、是否投流、现用工具

今天就先到这里。您更倾向先试用，还是我帮您约一次把企微配上再看自己的客户数据？
