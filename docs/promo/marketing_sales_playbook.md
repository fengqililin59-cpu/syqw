## 一、产品定位与信息框架

### 1.1 定位一句话

> **中数云科 = 唯一一款「可按需定制 + 可私有部署」的 AI 智能CRM**

不要把自己定位为"又一个CRM"。市场上CRM太多——纷享销客、销售易、悟空CRM、简道云……你要切的是**他们覆盖不了的缝隙**：

| 竞争对手 | 他们的死穴 | 你的机会 |
|---------|-----------|---------|
| 纷享销客/销售易 | 贵（年费5万起）、实施周期3个月+、无法私有化 | 你便宜、开箱即用、可私有 |
| 简道云 | 太通用、没有AI、业务流程弱 | 你有AI教练 + 审批工作流 |
| 悟空CRM | 开源但难用、缺乏行业模板 | 你有5行业模板 + 自定义字段 |
| 自研Excel | 零散、不可追溯、没有提醒 | 你全自动 + AI智能告警 |

**你的核心竞争力不是"功能多"，是"可配置 + 可私有 + AI内置"。**

### 1.2 三层信息结构（所有物料统一话术）

```
第一层（3秒钩子）：AI驱动的全行业智能CRM
第二层（10秒说服）：字段/管道/流程全可配 + 支持私有化部署 + AI教练内置
第三层（30秒转化）：14天全功能免费、¥299/月起、当天上线
```

## 二、目标客户画像

### 2.1 三层客户分级

#### 🥇 第一优先：B2B销售型中小企业（最容易成交）

- **画像**：10~100人，有销售团队，用企业微信，老板亲自盯业绩
- **行业**：软件/SaaS销售、工业设备、广告代理、咨询服务、企业服务
- **痛点**：客户散在微信/企微/Excel，销售离职客户跟着走，老板不清楚谁在跟什么
- **决策人**：老板 or 销售总监，一个人说了算
- **付费意愿**：高（能算出来ROI：一个销售月薪8000，流失一个客户损失几万）
- **触达渠道**：企业微信社群、知乎/B站、行业展会、老板圈子

**话术切入**：
> "你们公司销售怎么管客户的？如果有人离职，他的客户能无缝交接吗？"

#### 🥈 第二优先：有数据安全需求的机构（高客单价）

- **画像**：金融、医疗、教育、政务、法律服务
- **痛点**：数据不能上公有云，但团队管理很痛
- **决策人**：IT负责人 + 业务负责人，需要审批流程
- **付费意愿**：极高（私有化部署5~20万都算便宜）
- **触达渠道**：行业招标、IT服务商合作、软文/案例

**话术切入**：
> "你们行业数据合规要求高，公有云CRM风险太大——我们支持把整套系统部署到你们内网。"

#### 🥉 第三优先：连锁/多门店（规模化复制）

- **画像**：医美连锁、教培机构、房产中介、汽车4S店
- **痛点**：多门店客户数据不互通，总部看不到一线
- **决策人**：运营总监/老板
- **触达渠道**：行业媒体、行业协会、渠道代理

## 四、渠道策略

### 4.1 渠道矩阵（按投入产出比排序）

```
高ROI ◄────────────────────────────────► 低ROI
  │                                        │
  内容营销    社群裂变    抖音投放    SEO    线下
 (免费)      (免费)      (付费)    (慢)    (重)
```

### 4.2 抖音（最高优先级，暴力获客）

**账号定位**："一个帮中小企业搭AI销售系统的程序员"

**内容矩阵（每周3~4条）：**

| 类型 | 内容方向 | 频率 |
|------|---------|------|
| **痛点视频** | 模拟销售场景：客户丢在Excel里/销售离职带走客户/老板开会催数据 | 每周2条 |
| **功能演示** | 录屏实操：30秒配置一个行业字段、AI生成跟进话术全过程 | 每周1条 |
| **行业案例** | "医美机构用中数云科后，客户到店率提升40%"（匿名化） | 每周1条 |
| **创始人IP** | 你为什么做这个产品/行业吐槽/创业日记 | 每月2条 |

**投放策略：**
- 初期预算：¥3000~5000/月
- 定向：25-45岁、企业管理者/销售总监、一二线城市、关注"企业管理""CRM""销售技巧"
- 落地页：`landing.html`（已打通CRM留资）
- 投放时间：工作日早8-9点、午12-1点、晚8-10点

### 4.3 知乎（精准B端获客）

**策略**：不写广告，写"认知降维打击"

**选题方向：**
1. "中小企业有必要上CRM吗？——一个做了3年SaaS的人说实话"
2. "销售团队从10人扩到50人，怎么管客户不丢？"
3. "教培/医美/B2B的销售管理，为什么不能用同一套CRM？"
4. "自己开发一套CRM要多少钱？算完账我选择了买SaaS"
5. "私有化部署的CRM和SaaS版有什么区别？中小企业怎么选？"

每篇结尾自然引导到 中数云科，放落地页链接。

### 4.4 企业微信社群（裂变核心）

**建群逻辑**：
- 群名：`中数云科 · 销售管理实战群` （非产品群，先做价值群）
- 群价值：每周分享销售管理干货 + 免费CRM工具 + 行业交流
- 入群门槛：填过落地页表单的用户

**裂变机制**：
- 邀请3个同行业管理者入群 → 送1个月专业版
- 在群里做案例分享 → 送3个月专业版
- 转介绍成交 → 返佣20%

### 4.5 公众号/视频号（品牌阵地）

- 公众号：每周1篇深度文章（知乎回答稍改即发）
- 视频号：同步抖音内容，加企业微信跳转链接

### 4.6 SEO（长期免费流量）

**核心关键词**（按搜索量×转化率排序）：
1. `CRM系统 价格` — 月搜2000+
2. `私有化部署CRM` — 月搜800+
3. `企业微信CRM` — 月搜1500+
4. `AI客户管理系统` — 月搜500+
5. `销售管理软件 排行` — 月搜3000+

**SEO落地页**：为每个关键词做专题页（可复用 landing.html 结构）。

### 4.7 渠道合作伙伴（借力杠杆）

- **企微服务商**：帮企业做企微配置的服务商，推你的CRM可以分佣
- **行业SaaS集成**：和教培/医美的行业软件谈集成，互相导流
- **独立IT顾问**：给中小企业做技术咨询的自由职业者，推荐客户给你

## 六、销售转化剧本

### 6.1 14天试用期激活剧本（自动化 + 人工结合）

目前系统已有消息通知和智能跟进提醒，可以用于试用转化：

| 天数 | 自动触发 | 人工动作 |
|------|---------|---------|
| **D0** | 注册欢迎消息 | 企微加好友 + 问一句"你们主要做哪个行业的？" |
| **D1** | 新手引导任务列表 | 如未完成，发消息问"需要我帮你快速配好行业模板吗？" |
| **D3** | AI教练使用提示 | 检查是否导入了客户 — 没有的话发个导入教程 |
| **D7** | 一周数据回顾：你们团队这一周… | 电话/企微问使用感受 + 约演示 |
| **D10** | "你的试用还有4天"提醒 | 如高频使用：推进付费 |
| **D13** | "明天试用到期" | 最终挽留：发专属优惠码 |
| **D14+** | 降为免费版 | 7天后回访："降级后有什么不方便的吗？" |

### 6.2 销售话术框架（SPIN 模型）

**S - 情境问题（建立信任）：**
> "你们现在用什么管客户？Excel还是系统？"

**P - 难点问题（挖痛点）：**
> "销售离职了，他的客户怎么办？聊天记录能交接吗？"
> "老板想看每个人的跟进情况，你们怎么统计？"

**I - 暗示问题（放大痛苦）：**
> "如果一个高意向客户7天没人跟进，成交率会降多少？"
> "给老板汇报用Excel手动统计，销售每周花多少时间？"

**N - 需求-效益问题（带入方案）：**
> "如果每个客户都有AI自动生成跟进话术，新人上手能快多少？"
> "如果数据全在你自己的服务器上，安全和合规是不是放心很多？"

### 6.3 异议处理手册

| 客户说 | 你怎么回 |
|--------|---------|
| "太贵了" | "一个销售月薪8000，离职带走10个客户你损失多少？中数云科一年才299×12=3588。而且你可以先免费用14天，不合适不花钱。" |
| "我们有在用XX系统了" | "挺好的！不过XX支持按你们行业自定义字段吗？能私有化部署吗？——这些是我们的差异化。要不我帮你做个对比表？" |
| "我们公司太小用不上" | "其实越小越需要用系统——大公司有流程，小公司靠人记，最容易丢客户。我们免费版其实就够3人团队用了。" |
| "我们自己开发一个" | "我算过账：前端+后端+测试，3个人3个月，工资成本至少15万。我们专业版一年才3588，而且持续更新AI功能。" |
| "数据安全不放心" | "这就是我们做私有化部署的原因——你可以把整个系统装在自己服务器上，数据完全不经过我们。" |

3. **团队扩容包**：超出10人后，每人 ¥30/月——让成长型企业自然升级
